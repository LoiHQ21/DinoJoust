# Source provenance / caveats

This handoff uses files generated during the Crownfall discussions, plus the user's requests and directly supplied reference screenshots that were **not copied into this repository**.

## Original design source

- `docs/archive/Jurassic_Joust_Crownfall_GDD_v0.2.md` and `.docx`: earlier generated GDD, November 17 2026.
- `docs/design/GDD_v0.3.md`: canonical Markdown consolidation that updates camera/art/idea status and keeps the underlying original mechanics.
- `assets/animation/01_early_beast_lance_duel.gif`: original generated animation concept, 9 frames, earlier stylization.

## Visual assets

- `assets/roster/`: actual rigged 3D art prototypes and Blender-rendered previews, adapted from the Quaternius CC0 sources documented in [`assets/third_party/quaternius/README.md`](../../assets/third_party/quaternius/README.md). The source hashes and pack-specific license evidence are retained. These are not image-generator outputs or engine-validated production characters.
- `assets/concepts/current/`: most recent four generated concepts, chibi-faceted fantasy + behind-rider direction.
- `assets/concepts/archive_kingshot/`: older stylized rounded concept references.
- `assets/concepts/archive_early/`: early semi-real or presentation/moodboard concepts. AI-generated text/numbers in images may be wrong.

## Excluded external image references

The user supplied screenshots of a stylized Kingshot-like mobile game, a portrait third-person joust, and a fantasy roster promotional image to describe desired camera and visual style. These images are not treated as reusable game art or shipped in the GitHub starter. The production team should make original models, UI and logos.
