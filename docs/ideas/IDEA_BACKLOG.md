## Evaluation questions

Does the feature make the core **throttle + lance + dinosaur** loop more expressive, or simply add random chaos? Can a player understand the result without reading logs? Can the game run comfortably on mobile landscape? Can we ship it with existing rig families? Is the feature optional in accessibility/reduced-motion settings?
