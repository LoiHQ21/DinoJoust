# Example data definitions

These JSON files are deliberately **not gameplay-tested**. They illustrate a Codex-friendly, data-driven structure for dinosaur stats, arenas, equipment, game modes and match rules. Values are normalized placeholders, not real dinosaur mass/speed, not final scoring.

`python tools/validate_data.py` checks cross-references, datatypes, division legality, ranges and mode ids. It does **not** test game balance, physics, commercial output, or compatibility with an engine importer.
