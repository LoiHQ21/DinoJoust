# Assets and references

`roster/` contains the six **real rigged 3D art prototypes**, editable Blender sources, GLB exports, rendered previews, and validation evidence. Start with [the roster README](roster/README.md). `third_party/quaternius/` preserves the commercially reusable CC0 base files and source/license records.

`concepts/current/` is the latest approved visual **direction**, not a game engine screenshot or actual 3D mesh. Images were generated within prior design discussions.

`concepts/archive_kingshot/` is the earlier rounded chibi toy-like direction and `concepts/archive_early/` contains older semi-real and pitch boards. **Neither archive overrides current art or camera.** The GIF illustrates the original rider/dinosaur action idea, with earlier styling.

The latest shared user screenshots from other games/advertisements were used as references for camera and style and are intentionally not bundled as production textures/assets. The concept image folders do not contain 3D topology, UVs, rigs or animations; the new `roster/` directory does.

`ASSET_MANIFEST.json` lists files with hashes and statuses. Generated concept art is not a substitute for rights review before commercialization.
